# Roadmap

## 0.1: local foundations

AWS/Azure/GCP metadata connectors, validated evidence-backed ontologies, Wagner region/network/service/resource navigation and resource atlas, local snapshots, coverage, JSON import/export, and SVG export.

## Next

- Live validation in dedicated test accounts for all three providers and a published compatibility matrix.
- Discovery of available Azure subscriptions and GCP projects; explicit cloud identity confirmation.
- Azure/GCP progress per page, service-specific configuration hydration, and richer dependency coverage.
- Additional container grouping and upstream/downstream traversal beyond immediate neighbors.
- Snapshot comparison with deletion claims gated on compatible complete coverage.
- PNG export and local annotations that stay separate from observed cloud facts.
- Credential setup diagnostics and native installers.
- Performance benchmarks on large synthetic and real test environments.
- Container workload identity validation and optional credential helpers.

## Later

Multiple scopes in one workspace, Kubernetes and IaC imports, reviewed cross-cloud references, and richer ontology authoring. Any optional AI feature must leave discovery usable without an AI key and distinguish suggestions from observed facts.
