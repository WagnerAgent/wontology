# Glossary

| Term | Meaning |
| --- | --- |
| Cloud scope | The provider boundary being inspected: an AWS account, Azure subscription, or GCP project. |
| Resource | A cloud object with a stable provider-native identity. |
| Relationship | A directional, typed connection between resources, supported by observation evidence. |
| Dependency | A relationship expressing a specific reliance; shared placement alone does not establish one. |
| Snapshot | The resources, relationships, and coverage observed during one scan. |
| Coverage | A record of what a scan examined, skipped, could not access, or failed to collect. |
| Ontology | The shared vocabulary and structured model used to classify resources and their relationships. |
| Ontology bundle | A versioned set of resource classifications and relationship rules. |
| Unresolved reference | A configuration reference whose target cannot be identified among the observed resources. |
